# Bem-vindo ao Blue3 Drive! 🛰️

Este é o seu espaço — seguro, privado e do seu jeito.

## Como começar

- **Documentos** e **Fotos** começam vazias: o espaço é seu para organizar.
- **Modelos** traz arquivos prontos (documento, planilha, apresentação) para você
  criar rápido — use o botão **+ Novo** para começar a partir deles.
- Arraste arquivos para cá ou use **+ Novo** a qualquer momento.

> **Um local seguro para seus dados!**
